# Pumba Board

Канбан-доска в терминале (TUI) для задач ИИ-агентов. Все данные лежат в папке `.pumba/` проекта: `board.json` с колонками и правилами, `tasks/<ID>.md` с карточками и `AGENTS.md` с инструкциями для агентов, который программа пересобирает при каждом изменении.

Установка: `cargo install --path .` (крейт `pumba-board`, бинарник `pumba`).

Команды:
- `pumba [ПУТЬ]` открывает доску. Если `.pumba/` нет, программа предложит её создать.
- `pumba init [--tools СПИСОК | --no-agents] [ПУТЬ]` создаёт `.pumba/` и ставит агентов и скиллы для выбранных инструментов.
- `pumba install [--tools СПИСОК] [--force] [ПУТЬ]` ставит или обновляет только агентов и скиллы (claude, codex, cursor, copilot, opencode).
- `pumba --help` показывает полную справку.

Шаблоны агентов и скиллов лежат в `templates/` (общий набор для Claude Code в `templates/agents` и `templates/skills`, варианты для остальных инструментов в `templates/targets`) и встроены в бинарник. Дизайн будущего API для агентов описан в `templates/API-DESIGN.md`.
